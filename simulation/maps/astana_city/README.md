# Астана: оба берега

Проверочная объёмная версия мостовой развязки и её ограничения: `BRIDGES.md`.
Она создаётся отдельно и не заменяет общую городскую сеть.

Дорожная сеть в прямоугольнике, охватывающем административную границу
OSM relation 3087156. Это расширение охвата, а не подтверждение точности
каждого перекрёстка. Объекты за границей прямоугольника могут входить в
выгрузку для сохранения целых дорог. Здания пока не включены в SUMO.

## Воспроизведение

В окружении `emergency-mas`, из корня репозитория:

```sh
python simulation/maps/astana_city/build_city.py
python simulation/maps/astana_city/validate_city.py
sumo-gui -c simulation/maps/astana_city/coverage_demo.sumocfg
```

Первый скрипт скачивает OSM небольшими участками, сохраняя локальный кэш.
При превышении числа объектов участок делится на четыре. Повторный запуск
использует сохранённые данные. Сетевые ошибки не означают пустую область:
сборка прерывается, а уже скачанные файлы остаются.

Объекты объединяются по типу и ID, при различиях используется наибольшая
версия. Проверяется наличие всех узлов дорог. Неполные отношения ограничений
перечисляются в манифесте; их наличие требует проверки границ и маршрутов.
Для строгого повторения эксперимента нужно сохранить raw вместе с manifest.json:
выгрузка онлайн не является атомарным историческим снимком.

Используется общий набор проверенных правок `../astana_left_bank/osm_overrides.json`.
Значение null удаляет ошибочный тег в производной копии, исходники сохраняются.
Число полос по направлениям не выводится автоматически из противоречивых тегов.

Включено чтение стрелок поворотов и доступа по полосам. Автоматическое
добавление полос на предполагаемых съездах отключено. При отсутствии maxspeed
сохраняется прежний экспериментальный городской профиль SUMO с 50 км/ч
для основных городских типов; это допущение, не проверенный местный лимит.
Планы светофоров генерируются SUMO и не являются реальными городскими планами.

## Проверки и ограничения

`generated/validation.json` содержит подозрительные сужения, недостающие
числа полос и противоречия тегов. Два автомобиля с seed=42 должны завершить
маршруты между центральной левобережной и северной правобережной точками
в обоих направлениях. Телепортация отключена. Это проверка связности и
выполнимости двух маршрутов, а не всех дорог и не реалистичного трафика.

Отдельная карта без транспорта: `astana_city.sumocfg`.
Демонстрация открывается на паузе; нажмите Play в SUMO-GUI.

Исправленная развязка Мангилик Ел — Сарайшык (15 адресных поправок числа полос):

```sh
python simulation/maps/astana_city/review_interchange.py
sumo-gui -c simulation/maps/astana_city/generated/interchange/demo.sumocfg
```

Скрипт проверяет полосы, отсутствие ложного пересечения моста с нижним
основным ходом и 44 тестовых проезда. Это локальная проверка, не подтверждение
точности всей Астаны. Подробности: `CORRIDOR_REVIEW.md`.

Для детального просмотра используйте отдельные магистрали с подъездами:

```sh
python simulation/maps/astana_city/corridors.py --corridor all
sumo-gui -c astana_city_view.sumocfg
# Другой участок, например проспект Республики:
sumo-gui -c simulation/maps/astana_city/generated/corridors/respublika/view.sumocfg
```

Корневой `astana_city_view.sumocfg` теперь открывает **Мангилик Ел**, а не весь город.
Старая облегчённая сеть с `no-internal-links` и `junctions.minimal-shape` больше
не используется: она искажала вид перекрёстков. `build_view_network.py`
сохранён как совместимая точка входа для генерации подробного участка.

Вырезки создаются из полной сети, с внутренними траекториями и детализацией 10.
Сохраняются все именованные сегменты магистрали и все подъезды к их концам.
Их меньший размер должен снизить нагрузку; FPS на компьютере отдельно не измерялся.
Граничные перекрёстки пересчитываются: вырезки предназначены для осмотра,
не для обучения или сравнения метрик. Полная сеть не изменяется.
Манифест каждого участка содержит команду и SHA256 исходной сети.
`generated/corridor_audit.json` содержит инвентаризацию всех 20 магистралей,
OSM ID и отсутствующие теги полос/поворотов. Отсутствие тега — пробел данных,
не доказательство ошибки. Все магистрали пока имеют статус `requires_manual_review`.

Вручную ещё необходимо проверить соединения полос, островки, поворотные
карманы, отдельные светофоры, стоп-линии и мостовые развязки. Нельзя удалять
каждую поперечную линию SUMO: часть обозначает границы правил приоритета.
