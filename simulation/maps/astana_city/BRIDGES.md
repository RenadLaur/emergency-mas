# Мосты: проверочная 3D-версия развязки Мангилик Ел — Сарайшык

Статус: локальный прототип, не перенос всех мостов города в 3D.
Рабочая `astana.sumocfg` остаётся без изменений. В установленной SUMO-GUI
1.28.0 нет OpenSceneGraph; отдельный браузерный просмотр показывает ту же
геометрию полос, но не синхронизирован с движением автомобилей.

## Модель высот

- Нижние основные проезды: Z=0.
- Прямое полотно моста: Z=6,5 м — явное модельное допущение, не измерение.
- Съезды: высоты промежуточных узлов интерполируются по длинам связей.
- После построения узлов SUMO профиль высоты пересчитывается по фактической
  длине обрезанной полосы: иначе около границы перекрёстка появляются скачки.
- Внутренние соединения имеют высоту своего узла; проверяется непрерывность Z.
- Геометрия полотна, внешние ограждения и опоры в просмотре схематичные.
  Опоры исключаются из буферов нижних полос. Это не проект конструкций,
  не проверка несущей способности и не подтверждение нормативного габарита.

Автоматическое `osm.layer-elevation` было проверено, но не принято для этой
развязки: оно поднимало также части нижнего хода. Простого наличия layer=1
недостаточно, чтобы восстановить профиль съездов.

## Запуск и проверки

Предварительно должны быть собраны городская сеть и локальная развязка:

```sh
python simulation/maps/astana_city/review_interchange.py
python simulation/maps/astana_city/build_bridge_preview.py
```

Результаты — `generated/bridge_preview/`:

- `index.html`: автономный просмотр, без внешних библиотек и сети.
- `network.net.xml`: проверочная сеть с координатой Z.
- `view.sumocfg`: статический осмотр сети в SUMO (обычный GUI останется 2D).
- `validation.json`: сравнение с плоской сетью и тестовые проезды.
- `manifest.json`: команда, хеш исходной локальной сети, допущения.

На 15.10.2026: сохранены все 1236 внешних соединений полос, проверены
15 исправленных исходных дорог, нет разрывов высоты на соединениях,
максимальный проверенный уклон съездов 5,79% при экспериментальном пороге 8%.
Все 44 тестовых автомобиля завершили проезд с seed=42, телепортация отключена.
Это не проверка плотного трафика. В логе есть предупреждение о неиспользуемых
состояниях светофора на границе вырезки; модель сигналов не калибрована.

Просмотр допускает увеличение вертикального масштаба: ×1 — без искажения,
×3 и выше — только для удобства осмотра. Опоры не участвуют в физике SUMO.

## Дальнейший перенос

Перед включением в общую карту нужны проверка фактических высот/уклонов,
профилей переходов, ширины полотна, расположения реальных опор и ограждений.
Для остальных мостов необходим отдельный реестр и проверка пересечений
на разных уровнях. Нельзя назначать всем мостам одинаковые 6,5 м и объявлять
весь город точной моделью.

Документация SUMO: https://sumo.dlr.de/docs/Networks/Elevation.html
и https://sumo.dlr.de/docs/sumo-gui.html#3d_visualization .
