# Умный перекрёсток: контролируемый эксперимент

Это малый воспроизводимый полигон перед переносом агентной логики на карту
Астаны. В нём есть двухполосный регулируемый перекрёсток, потоки обычных
машин с трёх направлений и одна скорая, движущаяся с запада на восток.

Когда скорая приближается к стоп-линии, контроллер светофора даёт всем
направлениям красный на три секунды, пропускает скорую и возвращает штатную
программу. Обычные водители в той же очереди получают воспроизводимый профиль
и могут перестроиться в соседнюю полосу только после собственной задержки
реакции и только если SUMO считает манёвр безопасным.

Запуск проверки:

```bash
python simulation/sumo/intelligent_intersection/run.py
```

Визуальный запуск:

```bash
python simulation/sumo/intelligent_intersection/run.py --gui
```

После запуска в `output/` записываются сводка, последовательность событий и
профили реально обнаруженных водителей. Это модель для эксперимента, а не
утверждение о реальном поведении водителей Астаны.
