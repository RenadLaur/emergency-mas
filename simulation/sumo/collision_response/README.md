# Контролируемое физическое ДТП

Это маленький отдельный сценарий, а не прогноз реальной аварии в Астане. В нём
одна машина остановлена на полосе, а вторая **намеренно** получает опасную
команду через TraCI. SUMO фиксирует физическое соприкосновение бамперов;
результат записывается в `output/collisions.xml` и `output/run_summary.json`.

```bash
python simulation/sumo/collision_response/run.py
python simulation/sumo/collision_response/run.py --gui
```

Флаг `--collision.mingap-factor 0` исключает обычные предупреждения о малом
зазоре: событием считается именно физический контакт. После ДТП оба автомобиля
остаются на месте на 60 секунд, поэтому блокировка может влиять на поток.

Триаж пока получает только факт блокировки. Высокая скорость сохраняется в
журнале, но сама по себе не создаёт «раненых» или вызов пожарных. Для этого
нужны наблюдаемые признаки или откалиброванная по данным модель.
