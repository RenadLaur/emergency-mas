# ДТП назначенной скорой и переназначение

Это контролируемый тест цепочки восстановления операции:

```text
Dispatcher назначает ambulance_00
  -> SUMO фиксирует физическое ДТП
  -> ambulance_00 становится unavailable
  -> тот же call возвращается в pending
  -> Dispatcher назначает ambulance_01
  -> ambulance_01 прибывает
```

Первая скорая получает намеренно опасную команду только в этом изолированном
тесте. После контакта остановленная машина удаляется как упрощённая модель
очистки места происшествия, чтобы вторая скорая могла подтвердить завершение
исходного вызова. Этот приём не используется в обычных городских сценариях.

```bash
python simulation/sumo/dispatcher_collision_reassign/run.py
python simulation/sumo/dispatcher_collision_reassign/run.py --gui
```
