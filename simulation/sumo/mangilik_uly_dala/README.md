# Пилот: Мангилик Ел × Улы Дала

Первый перенос контролируемого эксперимента на геометрию городской SUMO-сети.
Выбран светофорный узел `cluster_1773372178_1773372179_1773372182_1773430682`
с координатами 51.0955265, 71.4269519.

Сценарий создаёт ровно 100 синтетических обычных автомобилей в четырёх
прямых направлениях и одну скорую на проспекте Мангилик Ел. Контроллер
разрешает только прямые сигнальные связи маршрута скорой после трёх секунд
общего красного и затем возвращает исходную программу.

```bash
python simulation/sumo/mangilik_uly_dala/run.py
python simulation/sumo/mangilik_uly_dala/run.py --disable-priority
python simulation/sumo/mangilik_uly_dala/run.py --gui
```

Первые две команды образуют воспроизводимый A/B-эксперимент: одинаковые
маршруты, 100 машин и seed 42; отличается только управление светофором.
Результаты сохраняются раздельно в `output/run_summary_baseline.json` и
`output/run_summary_priority.json`.

Это ещё не калиброванный трафик Астаны. Внешние границы вырезки искусственные,
спрос синтетический, а фазы светофора сформированы SUMO. До дипломного
эксперимента необходимо вручную подтвердить полосы и получить либо измерить
интенсивности и длительности фаз.
