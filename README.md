# Intelligent Multi Agent Emergency Logistics

Бакалаврский проект по моделированию и интеллектуальному управлению логистикой машин скорой помощи и пожарных автомобилей в городской среде.

## Текущий статус

Текущая работа — Inc 3: импорт и проверка карты Астаны. Собрана общая сеть
обоих берегов с адресными поправками полос, включая развязку Мангилик Ел —
Сарайшык. Подробная проверка остальных улиц ещё не завершена; это не точная
цифровая копия всего города. MARL и остальные компоненты диплома не считаются
завершёнными на основании готовности карты.

## Единая карта Астаны

Из корня репозитория в окружении `emergency-mas`:

```sh
sumo-gui -c astana.sumocfg
```

Это вся городская сеть, а не отдельная улица. Все адресные поправки применяются
при её сборке из общего файла `simulation/maps/astana_left_bank/osm_overrides.json`.
Отдельные вырезки не нужно склеивать: они производные от этой сети.
Окно открывается на паузе. Play запускает два контрольных автомобиля,
а не реалистичный городской поток. Полная карта может открываться и рисоваться
медленнее небольших участков; внутренняя геометрия перекрёстков не удаляется.

Если generated-файлов нет (они не хранятся в Git):

```sh
python simulation/maps/astana_city/build_city.py
python simulation/maps/astana_city/validate_city.py
sumo-gui -c astana.sumocfg
```

Первый запуск сборки при отсутствии raw-кэша требует сети. Для воспроизводимости
сохраните raw-снимки и манифест. Подробности: `simulation/maps/astana_city/README.md`.
`astana_city_view.sumocfg` — отдельный вид Мангилик Ел для детального осмотра;
основная точка входа в общую карту — **astana.sumocfg**.

Для демонстрации не короткого перекрёстка, а 4,3-километрового коридора
Мангилик Ел с разными уровнями Сыганак и Сарайшык:

```sh
python simulation/sumo/mangilik_corridor/run.py --gui
```

Сценарий создаёт 100 машин вне области наблюдения, прогревает поток и открывает
обзорный 2D-вид вместе с 3D-видом, следующим за скорой. Высоты мостов являются
относительными модельными допущениями, а не геодезическими измерениями.

## Быстрый запуск

Создать окружение на новой машине:

```bash
conda env create -f environment.yml
conda activate emergency-mas
```

Проверить установку:

```bash
pytest -q tests/test_environment.py
sumo --version
```

`sumo-gui` на macOS требует XQuartz. Он нужен только для графической визуализации; пакетные эксперименты используют `sumo` или `libsumo` без GUI.

## Наблюдаемое ДТП

Чтобы увидеть именно физическое столкновение, а не искусственно закрытую полосу:

```bash
python simulation/sumo/collision_response/run.py --gui
```

Это контролируемый тест: TraCI намеренно создаёт опасное поведение одной
машины. Он показывает фиксируемый SUMO контакт, блокировку и старт триажа;
он не является моделью вероятности ДТП в Астане. Подробнее —
`simulation/sumo/collision_response/README.md`.

При запуске `astana.sumocfg` используется презентационный профиль
`simulation/sumo/demo_viewsettings.xml`: он включает встроенную схему SUMO
`real world`. Для проверки геометрии перекрёстка её можно временно отключить
в GUI клавишами `Ctrl+J`; в демонстрации служебные соединители не должны
мешать восприятию дороги.

## Структура

`simulation/` содержит сети SUMO и сценарии. `agents/` содержит доменную логику, `ai/` — среды, baselines и обучение, `experiments/` — декларации запусков и результаты, `tests/` — автоматические проверки. Backend и frontend откладываются до готовности экспериментального ядра.
