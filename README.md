# Intelligent Multi Agent Emergency Logistics

Бакалаврский проект по моделированию и интеллектуальному управлению логистикой машин скорой помощи и пожарных автомобилей в городской среде.

## Текущий статус

Завершён Inc 1.2: репозиторий, воспроизводимое окружение и проверка инструментов. Следующий инкремент создаст маленький базовый сценарий SUMO; карта Астаны будет добавлена после проверки этого контура.

## Быстрый запуск

Создать окружение на новой машине:

```bash
conda env create -f environment.yml
conda activate emergency-mas
```

Проверить установку:

```bash
pytest -q tests/test_environment.py
sumo --version
```

`sumo-gui` на macOS требует XQuartz. Он нужен только для графической визуализации; пакетные эксперименты используют `sumo` или `libsumo` без GUI.

## Структура

`simulation/` содержит сети SUMO и сценарии. `agents/` содержит доменную логику, `ai/` — среды, baselines и обучение, `experiments/` — декларации запусков и результаты, `tests/` — автоматические проверки. Backend и frontend откладываются до готовности экспериментального ядра.
