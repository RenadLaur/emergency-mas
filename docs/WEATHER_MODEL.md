# Погодная модель MVP

## Назначение

Погода является параметром воспроизводимого сценария. Она одновременно меняет:

- коэффициент сцепления посещённых дорожных рёбер в SUMO;
- желаемую скорость всех типов машин;
- дальность, на которой модель уступания обычной машины замечает сирену;
- множитель времени реакции для следующего этапа — модели состояния водителя.

Это модель чувствительности, а не калибровка по данным Астаны. Значения ниже
нельзя представлять как официальные нормативы либо реальные средние величины.

| Условие | `surface_friction` | `speed_factor` | Видимость, м | Множитель реакции |
| --- | ---: | ---: | ---: | ---: |
| `dry` | 1.00 | 1.00 | 250 | 1.00 |
| `rain` | 0.75 | 0.88 | 120 | 1.15 |
| `snow` | 0.55 | 0.70 | 80 | 1.35 |
| `ice` | 0.25 | 0.45 | 40 | 1.65 |
| `fog` | 0.90 | 0.78 | 35 | 1.45 |

## Использование

```json
"weather": { "condition": "snow" }
```

Для контролируемого анализа чувствительности допустимы переопределения:
`surface_friction`, `speed_factor`, `visibility_meters` и
`reaction_time_multiplier`. Они сохраняются в `scenario.json`,
`run_metadata.json` и событии `weather_configured`.

Если активна `civilian_yielding`, эффективный радиус обнаружения равен минимуму
из `detection_range_meters` и видимости. На каждом занятом транспортом
внешнем ребре runner один раз устанавливает сцепление через TraCI. В SUMO для
условий с пониженным сцеплением включается `friction` device.

## Ограничения

Модель пока не описывает температуру покрытия по часам, осадки во времени,
снежные заносы, разные шины или видимость конкретного водителя. Эти параметры
будут калиброваться только после выбора источников и серии измерений; до этого
в дипломе они должны быть описаны как сценарные допущения.
