# Данные для модели ДТП и реагирования

Дата проверки: 2 ноября 2026 года.

## Главное ограничение

В открытых официальных источниках не найден набор по Астане с координатами
каждого ДТП, скоростью столкновения, числом бригад, фактическим временем
прибытия каждой службы и медицинским исходом. Поэтому такие значения нельзя
называть реальными параметрами Астаны. Их следует задавать как сценарные
диапазоны, фиксировать seed и проверять чувствительность результата.

## Правило состава сил

Не используем правило «маленькая скорость — только полиция, большая скорость —
две скорые». Скорость — признак риска, но не медицинский диагноз и не
официальное правило назначения.

В правилах реагирования закреплено, что первая получившая сведения служба
передаёт информацию в ЕДДС; она и диспетчер определяют необходимые службы.
В зависимости от обстоятельств могут участвовать полиция, скорая,
пожарно-спасательные и иные профильные службы.
[Правила оперативного реагирования при ДТП](https://www.adilet.zan.kz/rus/docs/V1600014387/compare).

Для MVP назначаем ресурсы по проверяемым признакам:

| Признаки в модели | Сценарный план реагирования |
| --- | --- |
| Нет предполагаемых пострадавших, нет блокирования/пожара/утечки | полиция; оформление и безопасность участка |
| Есть предполагаемые пострадавшие | полиция + минимум одна скорая |
| Несколько пострадавших | полиция + число скорых согласно числу пострадавших и доступным ресурсам |
| Зажатие, пожар, дым, утечка или опасный груз | полиция + скорая + пожарно-спасательный расчёт |

Извлечение людей из автомобиля относится к силам гражданской защиты; оно не
должно запускаться лишь из-за высокой скорости без признака зажатия или иной
опасности. [Пункты 13 и 16 правил](https://www.adilet.zan.kz/rus/docs/V1600014387/compare).
Патрульная полиция обеспечивает безопасность места, оценивает состояние
пострадавших и вызывает скорую при необходимости.
[Инструкция патрульной полиции](https://old.adilet.zan.kz/rus/docs/V2300031917).

## Практическое правило для экспериментов

Каждый параметр конфигурации обязан иметь одно из значений происхождения:

- `official_observed` — опубликованное фактическое среднее;
- `official_target` — норматив/целевое ограничение;
- `scenario_assumption` — явно заданный диапазон для sensitivity analysis;
- `calibrated` — оценён из скачанного набора, с указанием версии данных и кода.

В отчёте нельзя смешивать эти категории. Результаты модели с `scenario_assumption`
не называются прогнозом реальной работы служб Астаны.
