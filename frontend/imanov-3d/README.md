# 3D-профиль Иманова — локальный прототип

Статический Canvas-просмотр трёх слоёв: верхний мост Беласар, нижний сервисный проезд и пешеходно-парковочный контекст. Это демонстрация структуры интерфейса, а не расчёт физики и не утверждение инженерных высот.

Запуск:

```bash
python -m http.server 8875 --directory dist
```

Откройте `http://127.0.0.1:8875/`.

Источник идентификаторов и статусов: `simulation/maps/astana_city/review_registry.json`.
