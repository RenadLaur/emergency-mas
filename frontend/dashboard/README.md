# Диспетчерская панель — локальный прототип

Статическая визуализация для защиты диплома и проверки сценариев: карта участка, ресурсы, инцидент, таймлайн и анимированное движение экстренных служб.

Это не навигационный сервис и не копия 2ГИС. Геометрия на экране — упрощённая демонстрационная схема, а не источник данных для расчёта маршрута. Источник логики и маршрутов остаётся в `simulation/` и `agents/`.

Запуск из этой папки:

```bash
python -m http.server 8874 --directory dist
```

Откройте `http://127.0.0.1:8874/`.

Дальше этот слой можно заменить на MapLibre GL с локальными GeoJSON/тайлами OSM, не меняя сценарную модель.
